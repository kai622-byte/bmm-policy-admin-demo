# Project context

Answers to the guided-start questions. Synthetic: written for the reference spec from public research (see `../sources.md`).

## Who will use it

Customer service representatives who take calls from policyholders and agents, and their supervisors, who approve unusual changes.

## How many users

About 40 service representatives and 6 supervisors.

## What data it touches

Personal auto policies: policyholders, drivers, vehicles, premiums, payment plans and the history of every change. In this project, synthetic data only.

## Where it must run

In a web browser on the company's laptops. No mobile app.

## What it connects to

- The rating engine, which gives the full-term premium for a policy as it stands on any date. This slice treats that premium as an input.
- Billing, which holds installments and payments.
- Document production, which prints declarations pages, ID cards and notices.

## Project type

Web app.
