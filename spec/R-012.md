# R-012 · Each change produces the right documents

## Rule

When a change is issued, the system prepares the documents the policyholder needs, ready to send:

- a new declarations page (the summary of who and what is covered, and the premium) after every change;
- a new insurance ID card for a vehicle that was added;
- new ID cards for every vehicle after a change of address, because the card shows the address.

## Calculation examples

| ID  | Change         | → New declarations page | → New ID cards   | Rationale                           |
| --- | -------------- | ----------------------- | ---------------- | ----------------------------------- |
| E1  | Add vehicle    | Yes                     | New vehicle only |                                     |
| E2  | Remove vehicle | Yes                     | None             |                                     |
| E3  | Add driver     | Yes                     | None             | Cards are for vehicles, not drivers |
| E4  | Remove driver  | Yes                     | None             |                                     |
| E5  | Change address | Yes                     | All vehicles     | The address is printed on each card |
