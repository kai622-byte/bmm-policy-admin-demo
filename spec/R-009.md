# R-009 · Large return premiums need a supervisor's approval

## Rule

Send a mid-term change to a supervisor for approval when it returns more than $250.00 of premium to
the policyholder. The amount tested is the premium change for the rest of the term (R-004), not the
change in full-term premium. Additional premiums never need approval under this rule.
