# R-008 · Backdated additions need a statement of no loss

## Rule

Adding a vehicle or a driver adds coverage. When such a change is backdated more than 3 days, it
cannot be issued until the policyholder has signed a statement that no accident or loss involving
that vehicle or driver happened between the effective date and the day of the request, and the
representative has recorded it.

If the policyholder reports a loss in that period, the change cannot be backdated. It can be issued
effective the day of the request instead.

Removals and address changes never need the statement. This rule is separate from approval (R-007):
a change can need both.

## Calculation examples

| ID  | Change         | Days backdated | → Statement of no loss needed | Rationale                         |
| --- | -------------- | -------------- | ----------------------------- | --------------------------------- |
| E1  | Add vehicle    | 1              | No                            | Bought yesterday: within 3 days   |
| E2  | Add vehicle    | 3              | No                            | Exactly 3 days is not more than 3 |
| E3  | Add vehicle    | 4              | Yes                           |                                   |
| E4  | Add driver     | 10             | Yes                           |                                   |
| E5  | Remove vehicle | 20             | No                            | A removal adds no coverage        |
| E6  | Change address | 20             | No                            |                                   |
