# R-003 · Count the days left in the term

## Rule

The days left in the term are counted from the change's effective date to the expiration date. The
effective date itself counts as a day left; the expiration date does not.

The sample term runs from 2026-12-01 to 2027-06-01 and has 182 days.

## Calculation examples

| ID  | Effective date | → Days left | Rationale                             |
| --- | -------------- | ----------- | ------------------------------------- |
| E1  | 2027-03-03     | 90          |                                       |
| E2  | 2026-12-01     | 182         | The first day: the whole term is left |
| E3  | 2027-05-31     | 1           | The last day                          |
| E4  | 2027-01-22     | 130         |                                       |
| E5  | 2027-02-01     | 120         |                                       |
